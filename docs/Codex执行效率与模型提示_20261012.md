# Codex 执行效率与模型提示

运营版 3.0.9、旗舰版 3.0.10 同步更新。先在插件市场升级，再新开会话输入「启动星空」。有效年度会员沿用当前本机授权；原有产品重新生成导航即可刷新。

## 用户会看到什么

- 入口更精简，只读取当前任务规则，保留专业分析与报告深度。
- 主模型保持用户当前选择。步骤卡和导航显示同一份当前任务建议、下一步建议和升级条件，建议不表示模型已自动切换。
- 表格先用脚本整理并保留原始行。只有需要判断表头含义等狭窄辅助任务时才考虑 Luna，由主模型复核；财务结论、采购和广告动作仍按原有审核流程处理。
- S1 读取事实时不把嵌入图片编码直接灌入上下文；图片路径、来源、摘要和业务事实保留。

## 效果范围

同一个历史袋子组合 S1 案例的最后一组回放中，候选版用时150.331秒，对照177.814秒；输出Token为2374对2792，总Token为867982对1044799。分别减少约15.5%、15.0%、16.9%。这是单案例回放，包含工具调用与缓存上下文，不能折算为订阅费用，也不保证所有任务有同样改善。

报告图片、历史资料、成本缺口、目标利润反推与待审核结论仍需保留并核验。小表格优先脚本，子任务并非总能省量。本次没有接入ChatGPT网页/MCP桥接；Claude的模型与发布不在本轮更新范围。
