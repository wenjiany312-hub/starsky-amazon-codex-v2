# S1 产品开发决策透视与模型说明

适用：Codex 运营版 3.0.7、旗舰版 3.0.8。

## 先看清产品，再判断成本

组合产品按组件逐项展示图片、货源、SKU、规格、材质、用量、页价、MOQ、库存、重量与包装。缺项明确显示，避免把一张总图或一个页面价格当作整套产品事实。

利润分析区分广告前与广告后目标，反推所需售价与允许成本。缺失费用保留为空（null），代理或过期费用单独标记；最低佣金、组合费用和汇率需要各自的证据，不能用空值冒充零成本。

## 厂家资料与拿样建议

厂家回填覆盖装套、包装、标签、箱规、报价、交期与质量检查，关键空缺不能通过。拿样建议同时绑定市场同形态价格、具体成本场景与组件／包装／报价摘要，不能通过抬高假设售价得出通过结论。

报告交付、拿样建议与采购授权分别判断。样品、首批及补货保留接口；系统不会自动执行采购或擅自设定盈利窗口。

## 报告与流程

决策透视、市场穿透及最终 S1 报告共享当前模型，同步 Markdown/HTML。历史研究正文、备注和关键词保留；变更后检查报告是否失效，同步失败恢复原文件。

导航增加透视入口及失效提示，正文和展开区使用短段落，表格支持横向滚动，Markdown 图片使用本地资产。用户→产品→本轮输入逐层覆盖并保留来源，空模板不会清空已确认设置；个人目标不写成通用默认。

原九步流程及后补规则保留。用户明确只做 S1 时，不自动进入 S2；旧回执不能绕过新的范围或变更证据。

## Codex 模型推荐

S1–S5 主力分析推荐 GPT‑6.1 Sol：简单任务低推理、常规分析中推理，候选取舍、复杂约束与深度诊断按需要提高推理。Luna 用于明确的重复任务，难解冲突和高代价复核再使用 Astra；确定性计算、文件处理和渲染优先使用工具或脚本。

保留用户当前模型选择与旧模型备选。API 价格与 Codex 订阅用量分别看，不能用 API 单价推算套餐能完成多少任务；首次通过率、返工、耗时与实际用量仍需在同一业务案例中比较。本次不宣称跨模型质量等同或固定省量。

## 验收边界

软件路由、报告同步与导航检查不等于真实产品盈利验收。Windows/macOS 安装包检查、当前电脑安装、Mac 与 B/C 电脑验收、实际店铺任务需分别核对；本说明不宣称 Mac 或 B/C 电脑已测试。
