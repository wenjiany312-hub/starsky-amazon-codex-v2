# Codex 正式版 · 安装与授权

适用：当前付费正式版基础版，年度会员 365 天。正式版前缀 `SKYC2.`，与测试版、其他宿主的授权分开。

## 安装前准备

**一机一码，不支持更换设备，多台电脑需分别购买；购买后不接受退款。** 购买前请确认产品、版本档、系统环境与所绑定的电脑。

Windows 正式版市场需要 Git。首次安装请从 [Git 官方页面](https://git-scm.com/install/windows) 安装 Git for Windows，或运行 `winget install --id Git.Git -e --source winget`。安装后关闭旧安装窗口并重新运行入口；安装器会识别常见安装目录并为当前安装进程刷新 PATH。缺少 Git 时会明确提示，不继续修改原有市场登记。

先安装并登录官方 Codex；准备 Python 3.11+。首次安装需要联网获取运行依赖，安装器会建立专用环境。用户无需加入私有 GitHub 源码仓，也无需把 GitHub token 发给作者。

本交付为 ZIP 内的脚本安装器，不是经微软或 Apple 认证签名的 exe / dmg。发行清单的作者签名用于校验文件完整性，不能等同于操作系统代码签名认证。

## 授权与安装顺序

安装器出现“请输入授权 KEY”后，粘贴本产品、本机的完整授权码并按回车确认。看到“插件安装完成”且退出码为 `0` 才表示安装完成；退出码 `1` 表示未完成，请根据窗口标明的步骤排查。

安装顺序：先提示输入本机 Key（已有有效 Key 自动校验），校验通过后才下载 Python 依赖和执行安装。授权失败停在授权步骤，不创建运行环境、不下载依赖。会员的具体新版权限仍在业务安装前再次核验。

## Windows

1. 完整解压 Windows 包到普通文件夹，先打开 `00-使用说明.html`。
2. 双击 `申请授权.bat`，复制当前正式版的本机申请码，私信作者。
3. 确认购买、版本档与设备后，取得 `SKYC2.` 开头的授权码。
4. 双击 `安装与更新.bat`，完整粘贴授权，等待安装结果。若失败，保留错误文字供排查，不要重复删除配置或业务目录。
5. 退出并重开 Codex，在自己的产品文件夹新开会话，输入「启动星空」和「检测星空配置」。

## macOS

1. 完整解压 Mac 包，阅读 `00-使用说明.html` 和包内 `Mac安装指导.html`。
2. 运行 `申请授权.command`；若双击打不开，打开终端输入 `bash `（带末尾空格），把该文件拖入终端后回车。
3. 收到正式版授权后运行 `安装与更新.command`，按提示粘贴。
4. 首次运行若出现“无法验证开发者”等系统拦截，确认文件来自本仓官方发行页后，按包内 `Mac安装指导.html` 图解，在“系统设置 → 隐私与安全性”里点“仍要打开”。本包脚本未经 Apple 代码签名；Python 架构需与本机 Apple 芯片或 Intel 环境匹配。 参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
5. 重开 Codex 并新建会话，执行「启动星空」「检测星空配置」。

## 从测试版切换

先保存产品资料和私人服务配置，再使用正式版安装包取得新的正式版本机申请码。测试版 Key 不能安装正式版，正式版 Key 也不能用于测试版。业务资料和私人配置应保留；不要删除整套工作目录或用旧测试码反复重试。

## 多台电脑与设备绑定

每台电脑、每个产品分别申请机器码与授权，不复制另一台电脑的 Key。一机一码，不支持更换设备，多台电脑需分别购买。Codex 与 Claude Desktop 属于两个产品，即使在同一台 Mac 上使用，也需分别签发。
