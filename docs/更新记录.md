# Codex 正式版更新记录

## 3.0.2 · 2026-09-30

- 修复 Windows 授权 KEY 提示延迟显示：先显示“请输入授权 KEY”，再等待用户粘贴完整授权码并按回车确认。
- 正式版安装显示 Git 市场登记、插件安装步骤；失败时标明所在步骤，不输出凭证或配置内容。
- Git 市场安装和更新前检查 Git；缺少时给出安装指引，新装 Git 后可从常见安装目录补齐当前进程 PATH。
- 年度授权、会员自动更新、版本档次与导航功能保持原有规则。
- Windows 授权提示已通过真实启动脚本测试。安装失败请根据所在步骤排查；Mac 仍待实机测试。

## 3.0.1 · 2026-09-30

- 修复正式版导航快捷启动器误用插件入口目录，改为启动解锁后的业务内容；兼容旧版目录。
- Windows 桌面快捷方式和导航窗口采用深蓝金星图标，提供多尺寸 ICO；Mac App 随附对应图标。
- Git 市场禁止自动转换签名文件的换行符，修复 Windows 安装时的签名错误。
- 市场升级后同步刷新快捷启动器。有效年度会员沿用原授权码，不需要逐版换 Key。
- 本机 Windows 安装和导航启动已检查；另一台 Windows 与 Mac 仍需实机测试。

## 3.0.0 · 2026-09-30

- 建立独立付费正式版发行、签名与年度会员更新通道。
- 基础版包含 S1–S4 与 S5 第一、二部分，旗舰专属内容不进入本次发行。
- S5 进场确认报表／ERP 路线，诊断先核对总盘与数据证据。
- 增加配置检查、导航入口和 S5 接入说明。
- 完善正式版安装、授权、续期、联系入口和数据使用说明。

本次没有把待实测的跨电脑安装和第三方真实写入标记为验收通过。
