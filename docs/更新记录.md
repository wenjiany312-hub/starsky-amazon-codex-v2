# Codex 正式版更新记录

## 3.0.5 · 2026-09-30

- 修复安装 1688 时，安装包较新而业务安装记录较旧造成流程直接中止的问题。两套付费版均先校验授权，再自动补齐同包插件安装，随后检查 Chromium、MCP 初始化/工具列表/ping，通过后才登记。
- 旧安装包不会覆盖较新插件；错误提示明确显示安装包版本、已安装版本和最新下载入口。
- 保留 3.0.4 的授权先行、Mac 图解与 Finder 辅助文件兼容。

## 3.0.4 · 2026-09-30

- 两套付费版按无旧 1688 配置的条件检查登记顺序；Claude Desktop 补齐版本、服务文件及浏览器缓存路径检查。独立服务初始化、五项工具与 ping 已通过本地核验；账号登录和货源信息整理需使用用户自己的账号分别验证。
- Windows / Mac 安装与更新统一先验证授权，再准备运行环境和下载依赖；已有有效本机 Key 自动核验。
- Mac 安装包加入 `Mac安装指导.html` 离线图解，使用说明首页与“先读我”提供首次系统放行入口。
- 识别 Finder `.DS_Store` 与配对 AppleDouble 辅助文件；未知文件、业务文件缺失或摘要变化仍阻止安装，并显示文件名。
- 保留 3.0.3 的项目导航启动修复和既有年度会员规则。

## 3.0.3 · 2026-09-30

- 修复项目内悬浮窗启动器使用薄插件入口目录，导致找不到业务脚本、双击无反应的问题。
- 项目入口与桌面入口共用安装记录及解锁后的业务目录定位；升级后使用新版，保持启动器所在产品位置。
- 修正 Claude Desktop 正式版安装记录目录识别；Windows 批处理使用准确 CRLF，失败时显示原因。
- 升级后重新生成一次导航页，刷新已有项目启动文件。在文件资源管理器 / Finder 中双击；聊天文件链接只作定位或预览。
- 年度授权、会员更新与运营版服务范围保持原有规则。

## 3.0.2 · 2026-09-30

- 修复 Windows 授权 KEY 提示延迟显示：先显示“请输入授权 KEY”，再等待用户粘贴完整授权码并按回车确认。
- 正式版安装显示 Git 市场登记、插件安装步骤；失败时标明所在步骤，不输出凭证或配置内容。
- Git 市场安装和更新前检查 Git；缺少时给出安装指引，新装 Git 后可从常见安装目录补齐当前进程 PATH。
- 年度授权、会员自动更新、版本档次与导航功能保持原有规则。
- Windows 授权提示已通过真实启动脚本测试。安装失败请根据所在步骤排查。

## 3.0.1 · 2026-09-30

- 修复正式版导航快捷启动器误用插件入口目录，改为启动解锁后的业务内容；兼容旧版目录。
- Windows 桌面快捷方式和导航窗口采用深蓝金星图标，提供多尺寸 ICO；Mac App 随附对应图标。
- Git 市场禁止自动转换签名文件的换行符，修复 Windows 安装时的签名错误。
- 市场升级后同步刷新快捷启动器。有效年度会员沿用原授权码，不需要逐版换 Key。

## 3.0.0 · 2026-09-30

- 建立独立付费正式版发行、签名与年度会员更新通道。
- 包含 S1–S5 全流程；S5 支持手动报表与领星自动取数（赛狐接入指引已提供，持续适配中）。
- S5 进场确认报表／ERP 路线，诊断先核对总盘与数据证据。
- 增加配置检查、导航入口和 S5 接入说明。
- 完善正式版安装、授权、续期、联系入口和数据使用说明。
