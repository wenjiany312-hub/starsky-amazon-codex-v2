# 数据与使用边界

## 文件和外部服务

报告、产品资料和生成文件保存在用户选择的本地工作区。宿主、模型服务、MCP、ERP、飞书等外部服务在被调用时会接收对应请求和相关数据，具体范围取决于用户配置与任务内容；不承诺所有业务数据绝不离开本机。

用户使用自己的宿主账号、模型额度和第三方服务授权。星空会员费用不包含 Codex / Claude Desktop 账号、模型调用费、数据服务订阅、图片或视频生成费用。配置密钥请使用本机配置入口，不要粘贴进公开问题、截图或反馈文件。

## 会员登记和发行文件

作者通过授权登记助手记录客户姓名、联系方式、产品、本机申请码、签发与到期日期、版本档和备注，保存在作者本机台账，并同步到具有访问权限的飞书正式版登记表。正式版与测试版分表登记；联系信息和会员记录不放入本公开仓。

公开发行包的业务载荷使用 AES-256-GCM 加密，发行清单使用作者签名。安装器校验本机授权后解密安装；公开下载不等于取得业务内容。升级通道提供签名发行文件及设备对应的加密更新凭证，不发布明文授权码或私钥。

宿主运行时需要读取解密后的本地业务文件。加密用于控制公开发行与安装授权，不承诺已授权文件无法被复制或绝对不可破解。公开下载不代表开源许可；使用范围以双方确认的授权安排为准。

## 业务操作与结果

系统整理证据、生成文案、视觉方案、诊断和待审核候选。销量、利润、投放效果与模型节省比例不作固定承诺；缺失数据应补充或明确标注，不以推测冒充真实经营数据。

广告、Listing、ERP 等实际写入应按当前工具能力、用户明确指令和任务审核要求执行。生成报告或 Bulk 文件不代表已经上传、发布、投放或通过平台审核；发货、付款和经营决策由用户负责。

第三方服务权限、平台规则或网络状态变化可能影响可用性。会员获得服务期内已发布的对应档位更新，不代表所有规划功能已实现，也不代表所有操作系统和第三方服务组合都已完成实机验收。
