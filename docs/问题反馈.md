## 首次安装与 1688 检查

已有 Windows 1688 配置的检测成功，不代表另一台新电脑已完成首次安装。新电脑使用同一完整包的“安装1688”入口时，会在授权通过后自动补齐尚未安装或较旧的对应插件，再安装 1688；也可以先完成“安装与更新”再运行“安装1688”。1688 安装会先核验授权和版本，检查 Chromium 实际启动，再验证 MCP 初始化、五项工具和 ping，通过后才登记。重开基座并新建会话后再次调用 ping；账号登录和商品抓取分别验证。

Mac 包若报文件清单错误，请保留列出的缺失/未知文件名与检查记录路径。仅识别有系统格式的 Finder 辅助文件，未知业务文件仍拒绝；不要自行编辑已签名的安装包。卖家精灵提示密钥到期时，需要在服务商处核对/续期并更新本机密钥，重新安装星空不能延长第三方服务期。反馈时不要发送密钥或完整授权码。

安装包版本比已安装插件更旧时，不要反复运行旧包，也不要用旧包“安装与更新”覆盖新插件。提示会显示双方版本和最新下载地址；请下载完整新包并解压到独立目录后重试。
