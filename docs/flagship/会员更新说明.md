# Codex 旗舰版 · 年度会员更新

年度会员 365 天，包含对应旗舰档在服务期内发布的更新。首次取得本机旗舰授权；以后有效会员无需逐版换 Key。到期后保留已安装内容，后续新版需续期。

在 Codex「插件 → 市场」找到星空市场，点击「升级」，成功后新开会话输入「启动星空」。首次新版解锁需要一点时间，请等待输出结果；再核对实际插件版本。

使用广告终端时，继续检查引擎版本；需要升级则按终端提示执行。升级保留原有数据、配置和成本表。店铺写入必须由用户在网页审核报告中本人确认。

基础版会员不会因点击升级变成旗舰版。基础版转旗舰版需要匹配的旗舰安装包和该设备的旗舰授权；其他电脑不能沿用本机 Key。

市场更新失败时保留原版与资料，核对网络、产品、档位和会员日期，提供脱敏错误文字。不要发送完整 Key。也可下载仓库首页的旗舰 ZIP，运行「安装与更新」。
