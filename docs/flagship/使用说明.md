# Codex 旗舰版 · 开始使用

先在自己的产品文件夹新开会话，输入「启动星空」，选择 S1–S5。S1–S5 的通用用法见包内 `00-使用说明.html` 与 `01-口令速查.html`。

旗舰版新增 S5 第三部分的本机广告终端：输入「打开广告终端」，按引导安装、启动并完成店铺接入。可查看经营简报、销售与库存、利润和广告诊断，生成待审核建议。实际能力取决于已配置的数据源与接口权限。

自己的接口由用户在接入向导中填写，或提供已有凭据文件夹路径供程序导入；不要把密钥发进聊天。广告 API、SP-API、领星等第三方授权与会员是两回事，需要用户自行申请或配置。

推送建议先进入网页审核报告；用户本人审核并输入「确认推送」后才执行。安装成功、生成建议不等于已经修改店铺。

首次发布的 Windows/macOS 包使用同一份 alpha.17 引擎程序。Windows A 电脑已完成 alpha.17 运行验收；此次 macOS 包完成本地签名、归档及载荷一致性检查，Mac 实机安装仍需在目标设备验收。
