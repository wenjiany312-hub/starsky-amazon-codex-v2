# Codex 旗舰版 · 开始使用

先在自己的产品文件夹新开会话，输入「启动星空」，选择 S1–S5。S1–S5 的通用用法见包内 `00-使用说明.html` 与 `01-口令速查.html`。

旗舰版新增 S5 第三部分的本机广告终端：输入「打开广告终端」，按引导安装、启动并完成店铺接入。可查看经营简报、销售与库存、利润和广告诊断，生成待审核建议。实际能力取决于已配置的数据源与接口权限。

自己的接口由用户在接入向导中填写，或提供已有凭据文件夹路径供程序导入；不要把密钥发进聊天。广告 API、SP-API、领星等第三方授权与会员是两回事，需要用户自行申请或配置。

推送建议先进入网页审核报告；用户本人审核并输入「确认推送」后才执行。安装成功、生成建议不等于已经修改店铺。

本次 Windows/macOS 候选使用同一份 alpha.20 引擎程序；已完成本地签名、归档和来源文件逐字节核对。安装包发布后的 Mac 实机安装与界面验收仍需在目标设备完成。

## 购买、会员与接入范围

旗舰版价格 **¥1399 / 年 / 台，不送试用**。确认购买后不支持退款；产品本身无法按说明正常使用等质量问题，联系作者协助解决，按既有使用条款处理。一机一码，多台电脑分别申请。

会员有效期内可使用并接收对应旗舰版更新，到期日以授权为准；到期后已安装内容继续可用，只是不再收到后续更新，续费联系作者。

更新请运行「检查新版」或「安装与更新」，按提示完成，再重开宿主并新建会话。首次新包安装、插件更新与广告引擎升级分别核对，不保证一次操作自动完成全部步骤。

美国站、英国站已完整验证；其余站点按同一套流程接入，仍需核对实际接口权限、币种、日期和成本，不宣称已验证。领星广告写入尚未完成真实店铺实测。没有收益保证。

联系坚哥：个人微信备注“购买插件”，或公众号「跨境者说干货」后台留言；不要发送店铺凭据。本文不提供收款链接或账号。

## Windows 广告桌面入口

安装完成后，桌面有彩色「启动星空广告终端」和「停止星空广告终端」。双击启动直接进入综合看板；首次需要联网准备引擎，尚未接店铺时进入接入向导。日常打开看板不需要 AI，也不消耗模型 Token。

以后升级插件并完成正式版解锁后，入口跟随当前版本；下次启动自动同步引擎，保留已有配置和数据。关闭广告终端用停止图标，导航悬浮窗仍使用原导航图标。第一次准备需稍等；如启动失败，提示会指出下一步，在 Codex 中说「终端打不开了」进行检查。

综合看板右上角自动显示知识库/MCP连接检查，可以点击重检。通道工具目录通过仅证明连接和目录可用；实际产品/广告查询仍按业务流程核验。本次更新不自动执行广告建议。

## 模型提醒怎么看

模型行只提醒本步与下一步的建议，不表示已经切换模型。当前主模型可以沿用；需要调整时，在 Codex 自己的模型选择器里操作，位置以实际界面为准。

当前宿主的主力参考是 **GPT-6.1 Sol · 中**。型号与档位来自当前版本的模型方案；已有可用模型不会因为一条建议而被自动更换。

## 导航悬浮窗

Mac 按 Spotlight 搜「星空导航」，选择已安装宿主对应的入口；Windows 双击桌面「星空导航」快捷方式。也可以对助手说「打开悬浮窗」。

窗口中每步一行，依次看步号、名称、状态和官方模型名；较长内容可悬停查看完整名称。点击报告可打开当前产品的真实文件。

⚠️「验收未通过」表示还有数据或检查项没有补齐，按提示处理后再检查。它不会显示为绿色完成，也不会给出下一阶段口令。

## S1 新版：先验证需求，再算清生意

S1 会把需求、产品、供应商、成本、推广和 IP 归到同一份报告。首屏先看产品图、CT 规格、5 个关键答案、唯一结论和接下来 3 件事；详细内容按市场分析与机会、产品与货源、IP 与合规、推广难度、成本与定价、风险与翻转条件、采购落地清单展开。

### 毛利计算器

三个入口：悬浮窗点击「💰 毛利计算」；S1 第 6 步自动打开；在对话说「打开毛利计算器」。也可以直接说：

```text
快算：采购 33 元，695g，36×20×4cm，卖 24.99
```

同一口令的离线实际运行结果如下。它仍会列出缺项；条件快算不等于已确认利润。

💰 毛利快算（条件测算）

采购 ¥33 / 单包 695g / 36×20×4cm

| 售价 | 单件落地 | 广告前含预留毛利 | 广告后净利率 |
|---:|---:|---:|---:|
| $24.99 | $6.01 | 33.2% | 23.2% |

实际利润待确认：进口关税率、开票税点。
上表仅为条件情景：tax=0（待确认）；duty=0（待确认）。
仍用默认情景：头程单价、报关费、首批件数、汇率、入库配置费、月仓储费率、退货率；打开计算器补齐后存回重算。
本卡不构成采购授权；输入变化需重新验收。

支持美国 / 英国 / 德国 / 日本 / 澳大利亚。填写采购价、数量、产品和包装重量尺寸、运费及售价；可从当前产品带入的字段会自动带入，并区分页面数据、默认值和你确认的数据。

AWD 是备货入仓费用，不等于 FBA 配送费；计算器提供的第三方参考费率仍需在卖家后台核对。汇率会尝试联网更新，失败时显示缓存或默认汇率及时间；它不是 Amazon 结算汇率。

点击「存回产品」后，会更新成本、推广难度与 S1 报告，旧的确认结论会提示重新核对。保存计算结果不代表已批准采购或改动店铺。正式下单前，核对真实包装、物流、费率、税务与发票。
