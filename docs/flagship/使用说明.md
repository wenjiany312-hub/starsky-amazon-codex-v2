# 星空亚马逊 Agent · 使用说明

## 快速上手

完成授权安装后，重开 Codex，在自己的产品文件夹新建会话。输入“启动星空”，选择 S1–S5；接着选新手、老运营或企业资料路线。一次只处理当前提示，需要确认时再作决定。

运营版包含 S1–S5 全流程；旗舰版在此基础上增加星空广告终端。模型请在宿主的模型选择器里切换，提示不会代替你自动切换。

更新后新建案例使用当前流程；旧案例保留原进度，不强行换步骤。详细版本记录请看更新记录。

## S1 选品 · 9 步

帮助你判断需求、竞争、货源和利润；你确认自己的约束、选款和是否立项。

| 步骤 | 做什么 |
|---|---|
| 1 | 条件确认 |
| 2 | 方向筛选 |
| 3 | 需求验证门 |
| 4 | 选款 + 对标 |
| 5 | 1688 找货 + 产品 CT |
| 6 | 综合成本与定价 |
| 7 | 推广难度 |
| 8 | IP 与合规 |
| 9 | 综合报告 |

成本表与毛利快算共用算法；未确认费用会标明来源和缺口。综合报告先看产品、CT、五个问题和唯一结论，具体证据在后。关键条件未通过先补齐。

## S2 词库与文案 · 7 步

把产品事实、竞品和关键词变成可审核文案；你确认竞品范围、真实卖点和最终文案。

| 步骤 | 做什么 |
|---|---|
| 1 | 承接 S1 + 读词库资产 |
| 2 | 竞品分层挑选 |
| 3 | 导关键词表 |
| 4 | 清洗重判 + 补数 → 词库入库 |
| 5 | CT 映射 + 埋词地图 |
| 6 | 逐变体写文案 |
| 7 | 合规扫描 + 算法自检 → 交付 |

竞品先展示候选与理由，再由你确认；资料缺分层证据会明确拦截，不能把旧摘要当通过。文案按实际变体生成，合规禁用项命中时拦截交付；后台修改仍须本次审核和本人确认。

## S3 视觉 · 13 步

先学会产品再做整套图片与视频；你确认产品使用说明书和总规划，随后回填实际图片。

| 步骤 | 做什么 |
|---|---|
| 1 | 承接 S2 + 读 CT、文案、词库 |
| 2 | 素材全量盘点 + 视频抽帧 + 充足度检查 |
| 3 | 学会产品：产品使用说明书 |
| 4 | 卖点与购买决策 |
| 5 | 视觉总规划：7 图任务表 + 高级 A+ 模块表 |
| 6 | 主副图：选垫图 + 提示词 → 投喂包 |
| 7 | 主副图：出图 → 放回 → 后处理验收 → 最终版 |
| 8 | 高级 A+：投喂包 → 回填验收 → 最终版 |
| 9 | 产品视频：证据档位 → 分镜 + 关键帧 + 提示词 |
| 10 | 视频回填 → 抽帧对照 → 验收 → 最终版 |
| 11 | S3 交付 → S3→S4 交接 |
| 12 | 品牌故事（按需） |
| 13 | 品牌旗舰店（按需） |

主图、A+、视频依次推进。投喂包交给网页端同一个对话，图片或 ZIP 放回“放这里”，回复“已回填”。默认高级 A+，桌面版通过后再做手机版；资格提交前核实。

视频明确后补不阻塞交接，下一阶段不会将视频广告标为可用。品牌故事、旗舰店按需选择不做；必需图片、合规与本人确认仍不能跳过。

## S4 广告 · 7 步

生成新品上架前广告方案与上传表；你确认投放盘子、方案和真实 Seller SKU。

| 步骤 | 做什么 |
|---|---|
| 1 | 承接 S1–S3：词库索引、文案、图片与类目资料 |
| 2 | 判断产品与选择打法 |
| 3 | 定盘子：日预算、可接受 ACOS 与亏损上限 |
| 4 | 选词与确定起始出价 |
| 5 | 一页广告方案与批准 |
| 6 | 填写并确认 Seller SKU，生成 Bulk 表 |
| 7 | 上传四步指引与交接 S5 |

只停三次：第 3 步确认日预算、目标 ACoS、最大亏损、进攻或控损、测试天数；第 5 步看方案并批准；第 6 步逐变体填写实际 Seller SKU、选择是否投放并确认。

上架前方案可先完成第 1–5 步；没有实际 SKU 就停在第 6 步，不出上传表。ASIN 可后补，不能拿供应商货号代替自己的 Seller SKU。回来输入“填 SKU”或“继续 S4”，已批准且未改动的方案直接续做。

起始出价参考真实市场建议价，初期固定竞价；第 3 天无曝光按阶梯加价至上限。保本价用于赚亏与止损；市场建议和你能承担的上限冲突时，先让你决定。

报告先看打法、花多少、每单赚亏、要你拍板，再看流量放大、出价与止损。预估不是本店实际业绩，生成文件不等于已上传。

### 上传四步

1. 在广告后台手动新建以产品或系列命名的广告组合。
2. 上传本次 Bulk 表，创建广告活动及其子项。
3. 对照方案核对活动、关键词与成功失败行。
4. 将这次活动加入第 1 步的广告组合。

广告组合用于归集产品；广告组是广告活动内部放商品和关键词的一层。不要混用。处理报告放回原投喂目录。

## S5 运营 · 三条路线

帮助你按真实报表巡检和复盘；你选择接入路线、补齐成本与观察条件，并审核任何后台改动。本轮保留既有运营流程。

| 路线 | 条件与取数 | 改动怎么回后台 | 飞书日报 |
|---|---|---|---|
| 手动报表 | 从后台导出报表，放入指定投喂目录 | 审核后手动上传或操作 | 不含自动飞书日报 |
| 领星 | 完成原有授权与接入，按现有链路取数 | 本人审核后按既有写回流程执行并回读 | 原有每日 9 点飞书日报，需配置 |
| 赛狐 | 准备凭据，接入能力仍以实际配置与验证为准 | 接入未就绪时走手动报表与人工执行 | 不含自动飞书日报 |

S4 正常交接文件会指向现有 S5 入口；广告报表放在“S5_运营板块/_投喂_广告报表/”。缺失数据会列为缺口，不能当成零。

## 导航窗与步骤卡

输入“打开悬浮窗”，或双击桌面“星空导航”。点击实际产物可打开报告或目录；尚未生成会明确显示。导航缩短模型名称，保留型号与强度；步骤卡和报告使用完整模型名，两者对应同一个建议。

步骤卡只展示结论、实际调用的 Skill / 数据与知识依据、报告、模型和下一步。没有真实调用就不显示已调用。阶段末尾在一处选择“通过”“带待补通过”“先不验收”；强制门槛不因选择而放行，上游未验收只在风险里提醒一次。

## 投喂自己的资料

通过企业资料接入，把类目资料、成功案例和过往报表放入产品项目，先建资料清单并标明来源、日期、适用范围与冲突。S1–S3 按现有接入规则读取；S4 读取确认后的类目打法卡，无有效资料时用通用方案。

输入“导入类目打法”，提供当前资料位置并确认适用类目、站点；不能只改名称，确认后的打法会影响结构与预算。没有证据的经验不会当成官方规则，类目不符、过期或未确认时会回到通用方案。

## 常见问题

**选什么模型？** 看当前步骤提示；主模型负责判断，机械任务可使用较轻模型。导航与步骤卡一致，不能把建议当成已切换。

**工具或知识库没接通？** 输入“检测星空配置”。配置存在不等于实测成功，方法知识库也不能代替实时市场数据；详细接入看 MCP 配置必读。

**案例发现插件问题？** 保留诊断记录和原始文件，反馈作者；不自行改已安装插件、伪造验收或绕开门槛。

**日报和广告终端在哪？** 旗舰版输入“打开广告终端”，或使用安装时创建的桌面启动与停止入口。数据同步与具体后台操作沿用已有流程。

# JH-828 · 新品广告方案

已确认投放商品；请按上传指引手动操作。

## 打法

按通用母版 A：新品稳定出单。2个活动；JH-828-核心精准，日预算 20.10；JH-828-自动紧密，日预算 9.90。投放初期使用固定竞价。

## 花多少

日预算 30.00；测试 14天；累计亏损上限 200.00。达到任何一条止损线即停止并复核。

## 每单赚亏

每单广告前利润 6.75；按建议竞价和第三方预估转化率，每个广告单最保守约 -22.46；亏损上限约能换 8.91 个广告单。是条件估算，非本账户实际业绩。

## 要你拍板

1. 接受新品期亏损按建议价投，累计亏损封顶
2. 改善单件利润：核对券资格、去券或提价后重算
3. 低价慢跑：曝光更少，测试期可能收集不到足够数据
