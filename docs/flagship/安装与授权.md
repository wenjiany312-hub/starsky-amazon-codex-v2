# Codex 正式版 · 旗舰版安装与授权

旗舰版包含 S1–S5 工作流程，以及 S5 第三部分「AI 智能广告终端」。年度会员 365 天（1 年）；价格、付款及服务范围联系坚哥确认。运营版与旗舰版分别下载、分别授权。

## 新用户首次安装

1. 安装并登录自己的官方 Codex，准备 Python 3.11+、联网环境。Windows 先安装 Git for Windows；安装 Git 后关闭旧安装窗口，再运行星空入口。
2. 从仓库首页的**旗舰版下载**表选择 Windows 或 macOS ZIP，完整解压。不要下载 GitHub 自动生成的 Source code.zip / tar.gz。
3. Windows 双击 `申请授权.bat`；Mac 运行 `申请授权.command`。取得本机申请码后，私信坚哥发送「Codex 正式版 + 旗舰版 + Windows/macOS + 本机申请码」。
4. 确认购买后，领取绑定该电脑的旗舰授权。运行 `安装与更新.bat`（Mac 为 `.command`），按 KEY 提示粘贴完整 `SKYC2.` 授权码。原运营版授权不包含旗舰权限；不要使用另一台电脑的授权。
5. 看到「插件安装完成」且退出码为 0，再完全退出并重开 Codex，在自己的产品文件夹新开会话，输入「启动星空」「检测星空配置」。安装器会自动登记旗舰更新市场，用户不必手填 Git 分支。
6. 使用 S5 第三部分时输入「打开广告终端」，按引导安装并启动本机引擎，然后在接入向导里配置自己的店铺接口、成本表与简报时间。API 凭据由用户在本机填写，不发送给作者。

Mac 无法双击 `.command` 时，打开终端输入 `bash `（带末尾空格），拖入文件并回车；系统拦截按包内 `Mac安装指导.html` 操作。

## 授权和更新

一机一码；多台电脑分别申请授权，Codex 和 Claude 属于不同产品。会员期按北京时间计算，365 天包含签发当天，至到期日当天结束；以实际签发日期为准。到期后已安装内容保留，后续更新需续期。

旗舰会员后续在 Codex 的「插件 → 市场」点击升级，再新开会话说「启动星空」。市场拉取完成、授权解锁完成和引擎升级是三个步骤；应核对插件实际版本与引擎状态。

首次安装出错时保留错误文字，不删除旧配置或业务资料。授权码和 API 密钥不要贴进公开 Issue、群聊或截图。
