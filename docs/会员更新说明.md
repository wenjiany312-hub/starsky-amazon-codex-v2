# Codex 正式版 · 年度会员更新与续期

仅提供 365 天（1 年）年度会员。按北京时间计算，包含签发当天，至授权到期日当天结束；具体日期以作者签发结果为准。

## 更新操作

在 Codex 的 **插件 → 市场** 找到「星空 Codex 正式版」对应市场，点击 **升级（Upgrade）**。完成后新开会话，输入 **启动星空**。升级会拉取正式版发行文件，并根据本机授权解锁对应更新。

新版必须由作者向本正式版通道发布，并为有效会员提供对应档位的更新凭证。首次安装前仍需取得本机 Key；后续有效期内更新无需逐版换 Key。下载文件、拉取市场和成功解锁是不同步骤，以新会话实际加载的版本为准。

## 到期、续期与换设备

到期后已安装内容保留，后续新版本需续期。续期由作者延长原设备的会员权益并同步更新凭证；更换电脑需重新申请机器码与授权，不能直接沿用另一台电脑的码。升级旗舰档要等该档实际发布后单独办理。

## 正式版与测试版

本仓只发布付费正式版；测试版的 Key、登记表和发行通道独立。测试授权不包含正式版，不能因为测试通道更新或停止维护而自动转为正式会员。

## 更新失败

先确认产品、版本档、当前授权日期与网络状态。只拉取到文件但解锁失败时，保留旧版本和业务资料，将已脱敏错误发给作者；不要发送完整 Key、配置密钥或店铺数据。没有可确认的新版本时继续使用当前安装版本。
