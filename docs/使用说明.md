# Codex 正式版 · 日常使用

适用当前付费正式版运营版。先完成安装和本机授权，在产品工作文件夹中创建新会话。

## 从一项真实任务开始

- 「启动星空」：查看 S1–S5 板块入口。
- 「检测星空配置」：检查当前安装与任务所需配置，缺哪项补哪项。
- 「启动星空 S1，评估这个产品是否值得做」：提供产品事实、目标市场和已有竞品材料。
- 「启动星空 S2，根据这些真实关键词资料完善 Listing」：提供现有文案、真实导出和产品资料。
- 「启动星空 S3，整理这个产品的主副图方案」：提供实物图、尺寸和已确认卖点。
- 「启动星空 S4，诊断这份广告报表并生成待审核建议」：提供报表范围、时间与目标。
- 「启动星空 S5，检查这个店铺的经营情况」：先确认手动报表或领星路线（赛狐接入指引已提供，持续适配中，请先走手动报表），再提供对应数据或配置。

请优先使用已安装版本提供的口令速查。缺服务或真实数据时，先配置或补充资料；仅出现菜单不代表业务任务完成。

## 看懂配置体检

说「检测星空配置」，先看结论，再看外部 MCP、本地知识库、授权与更新、S5 可选接入和悬浮窗分组。已配置表示本机登记存在；本轮未试调的服务不算调用通过。需要检查 Sorftime / SIF 连接时，说「检测星空配置，联网试一下」。可选项目按任务需要补齐，必需项未就绪则先按提示处理。

## 按任务配置服务

市场数据、关键词、1688、出图／视频和 ERP 各自需要对应工具与用户授权。不要把所有服务都作为启动前置条件，只配置当前任务所需项目。知识库与本地脚本随安装处理；接入失败先看错误与配置检查结果。

安装包中的 `02-MCP配置必读.html`、`05-S5运营接入指南.html` 和 `S5接入模板` 给出配置入口。

## 查看成果和继续任务

报告、关键词包、文案、视觉方案、Bulk 候选和状态文件应在当前工作区查看。继续同一产品时保留已有材料、任务状态和历史备注，直接说明「继续这个产品」。仅修改指定字段时，说清目标字段与保留内容。

检查输出是否引用真实数据，确认版本、产品和平台是否正确。候选文件需审核，实际上传或后台修改应按当次明确指令与工具能力执行。

## 安装包里的说明

`00-使用说明.html`：完整操作；`01-口令速查.html`：可复制口令；`02-MCP配置必读.html`：服务配置；`03-MCP优惠购买入口.html`：外部服务信息；`04-知识库总览.html`：知识内容；`05-S5运营接入指南.html`：S5 路线及模板。

更新后以新安装包中的说明为准。遇到问题见 [问题反馈](问题反馈.md)，年度权益见 [会员更新说明](会员更新说明.md)。

## 模型提醒怎么看

模型行只提醒本步与下一步的建议，不表示已经切换模型。当前主模型可以沿用；需要调整时，在 Codex 自己的模型选择器里操作，位置以实际界面为准。

当前宿主的主力参考是 **GPT-6.1 Sol · 中**。型号与档位来自当前版本的模型方案；已有可用模型不会因为一条建议而被自动更换。

## 每一步的卡片怎么看

卡片把本步结论、实际用到的工具、报告和下一步放在一起。**有就显示，没有就不显示**：没调用 MCP 就没有 MCP 行，没有引用知识卡就没有知识库行。

以下是**历史陶艺案例的离线回放**，用新版卡片显示当时保存的步骤记录。只展示该步实际登记的能力和文件，不补造工具调用。它不是本次查询，也不能作为你当前产品的结论。

```text

🎯 结论：截图与页面已合并为JH-828现货测算；厂家未询，按用户授权继续；实际包装和贴标…
🧩 Skill：1688-product-detail-scraper
📦 报告：[03A_供应商数据补充清单.md](<历史陶艺案例\S1_选品板块\1688-product-detail-scraper\03A_供应商数据补充清单.md>) · [03B_供应商数据合并与复算.md](<历史陶艺案例\S1_选品板块\1688-product-detail-scraper\03B_供应商数据合并与复算.md>)
```

|---|---|
| 🎯 结论 | 这一步得到了什么结果，还有什么缺口。 |

## 导航悬浮窗

Mac 按 Spotlight 搜「星空导航」，选择已安装宿主对应的入口；Windows 双击桌面「星空导航」快捷方式。也可以对助手说「打开悬浮窗」。

窗口中每步一行，依次看步号、名称、状态和官方模型名；较长内容可悬停查看完整名称。点击报告可打开当前产品的真实文件。

⚠️「验收未通过」表示还有数据或检查项没有补齐，按提示处理后再检查。它不会显示为绿色完成，也不会给出下一阶段口令。

| 底部工具 | 怎么用 |
|---|---|
| 导航页 | 打开全部步骤和报告链接。 |

## S1 新版：先验证需求，再算清生意

S1 会把需求、产品、供应商、成本、推广和 IP 归到同一份报告。首屏先看产品图、CT 规格、5 个关键答案、唯一结论和接下来 3 件事；详细内容按市场分析与机会、产品与货源、IP 与合规、推广难度、成本与定价、风险与翻转条件、采购落地清单展开。

### S1 九步一览

下表由新版流程直接生成，步骤名、产出与停顿点保持一致。

| 步骤 | 产出 | 哪里会停下来问你 |

工厂报价不再卡流程：先用 1688 页面已找到的价格、重量和包装数据测算，标清来源与待确认项。厂家回复后再重算；缺少关键价格或重量时会明确提示。

用户主要确认选方向、需求不足时的去留、定位变更、选货源与 IP 红灯的处理。更改尺寸、用途或人群可能影响原需求结论，系统会先让你确认定位。

**旧案例保留原进度和原九步；新案例使用新版九步。** 旧案例不会因为升级被改成另一个步骤，也不会自动替你重做选款。

### 条件卡怎么选

先选模式、站点和价带，再看 **④ 目标毛利（默认 40%）**。这里是广告前目标毛利；首批预算可选填，预算留空也能开始。已有供应商和产品资料可以直接带入。

下面是新版条件确认脚本实际运行后，由当前步骤卡生成器输出的离线示例；不是你当前产品的选品结论。

### 毛利计算器

三个入口：悬浮窗点击「💰 毛利计算」；S1 第 6 步自动打开；在对话说「打开毛利计算器」。也可以直接说：

```text
快算：采购 33 元，695g，36×20×4cm，卖 24.99
```

同一口令的离线实际运行结果如下。它仍会列出缺项；条件快算不等于已确认利润。

💰 毛利快算（条件测算）

采购 ¥33 / 单包 695g / 36×20×4cm

| 售价 | 单件落地 | 广告前含预留毛利 | 广告后净利率 |
|---:|---:|---:|---:|
| $24.99 | $6.01 | 33.2% | 23.2% |

实际利润待确认：进口关税率、开票税点。
上表仅为条件情景：tax=0（待确认）；duty=0（待确认）。
仍用默认情景：头程单价、报关费、首批件数、汇率、入库配置费、月仓储费率、退货率；打开计算器补齐后存回重算。
本卡不构成采购授权；输入变化需重新验收。

支持美国 / 英国 / 德国 / 日本 / 澳大利亚。填写采购价、数量、产品和包装重量尺寸、运费及售价；可从当前产品带入的字段会自动带入，并区分页面数据、默认值和你确认的数据。

美国 FBA 费按适用费表试算，也能手动覆盖；其他站点需填实际配送费。英 / 德 / 日 / 澳的 VAT 默认分别为 20% / 19% / 10% / 10%，实际纳税口径请核对；采购退税与发票税点需要按实际情况填写，不默认替你认定享受退税。

AWD 是备货入仓费用，不等于 FBA 配送费；计算器提供的第三方参考费率仍需在卖家后台核对。汇率会尝试联网更新，失败时显示缓存或默认汇率及时间；它不是 Amazon 结算汇率。

点击「存回产品」后，会更新成本、推广难度与 S1 报告，旧的确认结论会提示重新核对。保存计算结果不代表已批准采购或改动店铺。正式下单前，核对真实包装、物流、费率、税务与发票。

### 报告在哪里

每一步默认保留一份给人看的报告。导航链接指向当前产品的实际报告；图片、视频作为独立证据保留，表格需要时再导出。

```text
产品项目/
  00_总控/紧凑业务报告/S1/
    01.md … 09.md
  阶段_S1_选品可行性研究报告.md
  阶段_S1_选品可行性研究报告.html
```

最终报告末尾是采购落地清单：样品、厂家问题、合同、发票与入仓事项逐项记录。清单用于跟进，未填满不意味着可以跳过风险，也不会单独阻断报告生成。
