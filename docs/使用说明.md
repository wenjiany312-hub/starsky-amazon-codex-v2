# Codex 正式版 · 日常使用

适用当前付费正式版运营版。先完成安装和本机授权，在产品工作文件夹中创建新会话。

## 从一项真实任务开始

- 「启动星空」：查看 S1–S5 板块入口。
- 「检测星空配置」：检查当前安装与任务所需配置，缺哪项补哪项。
- 「启动星空 S1，评估这个产品是否值得做」：提供产品事实、目标市场和已有竞品材料。
- 「启动星空 S2，根据这些真实关键词资料完善 Listing」：提供现有文案、真实导出和产品资料。
- 「启动星空 S3，整理这个产品的主副图方案」：提供实物图、尺寸和已确认卖点。
- 「启动星空 S4，诊断这份广告报表并生成待审核建议」：提供报表范围、时间与目标。
- 「启动星空 S5，检查这个店铺的经营情况」：先确认手动报表或领星路线（赛狐接入指引已提供，持续适配中，请先走手动报表），再提供对应数据或配置。

请优先使用已安装版本提供的口令速查。缺服务或真实数据时，先配置或补充资料；仅出现菜单不代表业务任务完成。

## 看懂配置体检

说「检测星空配置」，先看结论，再看外部 MCP、本地知识库、授权与更新、S5 可选接入和悬浮窗分组。已配置表示本机登记存在；本轮未试调的服务不算调用通过。需要检查 Sorftime / SIF 连接时，说「检测星空配置，联网试一下」。可选项目按任务需要补齐，必需项未就绪则先按提示处理。

## 按任务配置服务

市场数据、关键词、1688、出图／视频和 ERP 各自需要对应工具与用户授权。不要把所有服务都作为启动前置条件，只配置当前任务所需项目。知识库与本地脚本随安装处理；接入失败先看错误与配置检查结果。

安装包中的 `02-MCP配置必读.html`、`05-S5运营接入指南.html` 和 `S5接入模板` 给出配置入口。

## 查看成果和继续任务

报告、关键词包、文案、视觉方案、Bulk 候选和状态文件应在当前工作区查看。继续同一产品时保留已有材料、任务状态和历史备注，直接说明「继续这个产品」。仅修改指定字段时，说清目标字段与保留内容。

检查输出是否引用真实数据，确认版本、产品和平台是否正确。候选文件需审核，实际上传或后台修改应按当次明确指令与工具能力执行。

## 安装包里的说明

`00-使用说明.html`：完整操作；`01-口令速查.html`：可复制口令；`02-MCP配置必读.html`：服务配置；`03-MCP优惠购买入口.html`：外部服务信息；`04-知识库总览.html`：知识内容；`05-S5运营接入指南.html`：S5 路线及模板。

更新后以新安装包中的说明为准。遇到问题见 [问题反馈](问题反馈.md)，年度权益见 [会员更新说明](会员更新说明.md)。

## 模型提醒怎么看

模型行只提醒本步与下一步的建议，不表示已经切换模型。当前主模型可以沿用；需要调整时，在 Codex 自己的模型选择器里操作，位置以实际界面为准。

当前宿主的主力参考是 **GPT-6.1 Sol · 中**。型号与档位来自当前版本的模型方案；已有可用模型不会因为一条建议而被自动更换。

## S1 新版：先验证需求，再算清生意

S1 会把需求、产品、供应商、成本、推广和 IP 归到同一份报告。首屏先看产品图、CT 规格、5 个关键答案、唯一结论和接下来 3 件事；详细内容按市场分析与机会、产品与货源、IP 与合规、推广难度、成本与定价、风险与翻转条件、采购落地清单展开。

### 毛利计算器

三个入口：悬浮窗点击「💰 毛利计算」；S1 第 6 步自动打开；在对话说「打开毛利计算器」。也可以直接说：

支持美国 / 英国 / 德国 / 日本 / 澳大利亚。填写采购价、数量、产品和包装重量尺寸、运费及售价；可从当前产品带入的字段会自动带入，并区分页面数据、默认值和你确认的数据。

AWD 是备货入仓费用，不等于 FBA 配送费；计算器提供的第三方参考费率仍需在卖家后台核对。汇率会尝试联网更新，失败时显示缓存或默认汇率及时间；它不是 Amazon 结算汇率。

点击「存回产品」后，会更新成本、推广难度与 S1 报告，旧的确认结论会提示重新核对。保存计算结果不代表已批准采购或改动店铺。正式下单前，核对真实包装、物流、费率、税务与发票。

## S2：词库留得住，文案能逐项核对

在 Codex 的同一个产品项目里说“启动 S2 文案”，按卡片承接 S1 资料。已有产品规格、用途、人群、场景和痛点会继续使用；缺关键事实会标出，不把猜测写成卖点。

### 词库资产是什么，重跑怎么用

词库资产就是这个产品系列长期使用的词袋，保存在系列根目录 `_词库资产/`。再导一份新表，会先读旧词库再合并，保留首次发现日期与历史；颜色、尺寸等子款分别核对可用词和已使用位置。周搜索量、月搜索量分开看，原始导出表保留。

主词库用于选词；品牌词单独留存，不能直接写进自己的文案；否定词用于记录不匹配的词；自定义合规词用于记住你的禁用要求。埋词地图告诉你词放在哪个字段；本轮只写 S2 的位置，图片文件名不算埋词。

竞品默认按 BSR 前、中、后段与新品榜分层 6/6/5/3 挑选。补位写清理由，不足就如实写实际数量，等你确认，不凑不相关产品。导表后先清洗、生成当前待审清单并完成裁决，再生成最终计划并补数；最后按同一计划合并结果。原表或裁决改变时重新计划。

补数优先用宿主本次真正可调用的原生工具。**配置存在不代表可调用**；缺工具或失败时显示缺项与可执行的手工方案，报告按实际逻辑请求写“成功 X/Y、缺 Z”，不把重试次数当完成数。

### 按变体核对，按字段复制

每个变体先完成自己的一整套，再看下一款：标题、亮点、五点、纯文字描述、HTML 描述、Search Terms、问答和后台属性。字段按“英文原文 → 中文 → 埋词 → 计数”展示；完整出现与仅分词覆盖分开，标题和亮点只认完整出现。

| 字段 | 本项目写作目标 | 限制 / 计数说明 |
|---|---|---|
| 标题 | 68–75 字符 | ≤75 字符 |
