## 下载旗舰版 · 星空 AI 智能广告

**每天早上一份经营简报，告诉你店铺昨天怎么样、今天该调什么；你点头，才改。**

星空 · AI 智能广告，把你自己的亚马逊店铺数据，变成每天一份能直接行动的经营简报。

连上你自己的店铺后，它每天自动汇总各站点的销售、订单、广告花费和扣掉广告后的利润（估算），盯住断货、广告突然不花钱、库存撑不到新货这类问题，并告诉你今天先处理哪几件事、每条为什么这么建议。

你认可的建议，勾选后生成一份审核报告，逐条看清楚“现在是什么、改成什么”，**由你本人确认**才会写入店铺；写完自动回读核对，不满意可以回滚。

### 能做什么

- **每日经营简报**：销售、订单、广告花费、扣广告后利润（估算）和 TACoS，支持网页及飞书。
- **库存和广告提醒**：断货风险、补货节奏、美国站 AWD 库存、活动不花钱等问题集中查看。
- **有依据的建议**：今天先处理什么、为什么这样建议；数据不够时保留“继续观察”。
- **本人确认后执行**：审核报告展示当前值与目标值，写入后回读；撤回同样需要本人确认。
- **五点文案草稿**：英文敏感词过滤与亚马逊预检，非英语文案需人工复核。
- **灵活接入**：可先接销售与库存，或用已有 ERP 获取广告数据。领星通道已在英国站完成真实店铺写入实测；领星通道不能新建活动或加商品投放。

## 首次安装

1. 安装并登录你自己的官方 Codex，准备 Python 3.11+ 与联网环境。Windows 需先安装 Git for Windows（见 [安装与授权](docs/安装与授权.md)）。
2. 下载对应平台 ZIP，完整解压，运行「申请授权」，私信提交本机申请码。Mac 首次运行如遇系统拦截，见包内 `Mac安装指导.html`（按图解点“仍要打开”）。
3. 收到 **`SKYC2.`** 开头的正式版授权后，运行「安装与更新」，按提示粘贴授权。
4. 完成安装后重启宿主，在自己的产品工作目录新开会话，输入 **启动星空**；再输入 **检测星空配置** 核对本机安装与所需配置。
5. 根据任务配置市场数据、1688、ERP 等服务。配置完成不等于业务验收，应使用自己的资料跑一次实际任务。

安装包内提供离线使用说明、口令速查、MCP 配置必读、MCP 优惠购买入口、知识库总览、S5 运营接入指南及接入模板。星空不重新分发官方宿主，不提供宿主账号或模型额度。

## 年度会员如何更新

在 Codex 的 **插件 → 市场** 找到「星空 Codex 正式版」对应市场，点击 **升级（Upgrade）**。完成后新开会话，输入 **启动星空**。升级会拉取正式版发行文件，并根据本机授权解锁对应更新。

正式版只接收本正式版通道的对应档位更新。旧测试版授权不会自动转换成正式版授权；授权绑定申请时的电脑，不支持换机；跨产品或版本档需联系作者分别办理。
