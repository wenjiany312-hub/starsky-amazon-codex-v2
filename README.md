## 下载旗舰版 · 星空 AI 智能广告

**每天早上一份经营简报，告诉你店铺昨天怎么样、今天该调什么；你点头，才改。**

星空 · AI 智能广告，把你自己的亚马逊店铺数据，变成每天一份能直接行动的经营简报。

连上你自己的店铺后，它每天自动汇总各站点的销售、订单、广告花费和扣掉广告后的利润（估算），盯住断货、广告突然不花钱、库存撑不到新货这类问题，并告诉你今天先处理哪几件事、每条为什么这么建议。

你认可的建议，勾选后生成一份审核报告，逐条看清楚“现在是什么、改成什么”，**由你本人确认**才会写入店铺；写完自动回读核对，不满意可以回滚。

### 能做什么

- **每日经营简报**：销售、订单、广告花费、扣广告后利润（估算）和 TACoS，支持网页及飞书。
- **库存和广告提醒**：断货风险、补货节奏、美国站 AWD 库存、活动不花钱等问题集中查看。
- **有依据的建议**：今天先处理什么、为什么这样建议；数据不够时保留“继续观察”。
- **本人确认后执行**：审核报告展示当前值与目标值，写入后回读；撤回同样需要本人确认。
- **五点文案草稿**：英文敏感词过滤与亚马逊预检，非英语文案需人工复核。
- **灵活接入**：可先接销售与库存，或用已有 ERP 获取广告数据。领星通道已在英国站完成真实店铺写入实测；领星通道不能新建活动或加商品投放。
