## 首次安装

1. 安装并登录你自己的官方 Codex，准备 Python 3.11+ 与联网环境。
2. 下载对应平台 ZIP，完整解压，运行「申请授权」，私信提交本机申请码。
3. 收到 **`SKYC2.`** 开头的正式版授权后，运行「安装与更新」，按提示粘贴授权。
4. 完成安装后重启宿主，在自己的产品工作目录新开会话，输入 **启动星空**；再输入 **检测星空配置** 核对本机安装与所需配置。
5. 根据任务配置市场数据、1688、ERP 等服务。配置完成不等于业务验收，应使用自己的资料跑一次实际任务。

安装包内提供离线使用说明、口令速查、MCP 配置必读、MCP 优惠购买入口、知识库总览、S5 运营接入指南及接入模板。星空不重新分发官方宿主，不提供宿主账号或模型额度。

## 年度会员如何更新

在 Codex 的 **插件 → 市场** 找到「星空 Codex 正式版」对应市场，点击 **升级（Upgrade）**。完成后新开会话，输入 **启动星空**。升级会拉取正式版发行文件，并根据本机授权解锁对应更新。

正式版只接收本正式版通道的对应档位更新。旧测试版授权不会自动转换成正式版授权；更换电脑、跨产品或升级版本档，请联系作者核对并重新办理。
